# Калькулятор на Python

## Описание проекта
Простой калькулятор с базовыми математическими операциями: сложение, вычитание, умножение и деление.

## Как установить и запустить
1. Убедитесь, что у вас установлен Python 3.x
2. Скачайте репозиторий: `git clone https://github.com/ваш_username/ваш_репозиторий.git`
3. Перейдите в папку проекта: `cd ваш_репозиторий`
4. Запустите калькулятор: `python calculator.py`

## Примеры использования
```python
from calculator import add, subtract, multiply, divide

print(add(5, 3))        # Вывод: 8
print(subtract(5, 3))   # Вывод: 2
print(multiply(5, 3))   # Вывод: 15
print(divide(6, 3))     # Вывод: 2.0
